## Зачем это

Покупатель платит по QR или картой бесплатно, а продавец отдаёт банку комиссию и закладывает её в цену.
Проект считает, сколько продавцу стоит один платёж картой, через СБП и в цифровых рублях, и объясняет, почему покупки уходят в СБП.
Исследование оформлено как открытый калькулятор, в котором любой бизнес может посчитать свою цену платежа.

## Ключевые цифры

| | |
|---|---|
| **56 млн** | операций СБП в сутки (II кв. 2026) |
| **103 трлн ₽** | объём СБП за 2025 год, ×3,3 к 2023 |
| **55%** | переводов граждан идут через СБП (+7 п.п. за год) |
| **11,90 ₽ vs 31–52 ₽** | цена чека 1 700 ₽ для продавца: СБП vs карта с НДС |
| **0,57%** | ставка эквайринга, при которой карта сравнялась бы с СБП (рынок: 1,5–2,5%) |
| **≈220 тыс.** | кошельков цифрового рубля за первый месяц, ×3,7 к ожиданию ЦБ |
| **≈37%** | доля СБП в объёме хищений во II кв. 2026 |

## Пять выводов

1. СБП стала инфраструктурой: 103 трлн ₽ за год, 55% переводов, 3,3 млн продавцов.
2. В покупках решает цена для продавца, а в переводах важнее, что они бесплатны (почти половина переводов делается самому себе).
3. Разрыв сохранился и в 2026 году: даже с НДС на эквайринг и тарифами ЦБ карта дороже СБП в 2,6–4,4 раза.
4. У цифрового рубля есть цена и спрос. Комиссия 0% в 2026 и 0,3% с 2027 года, это в 2,3 раза дешевле СБП; мешает привычка.
5. В 2026 году цену платежа сильнее технологий изменили налоги, тарифы и законы, то есть рынок двигает регулятор.


## Быстрый старт

```bash
pip install -r requirements.txt
cd analysis
python test_payment_cost.py          # проверить, что расчёты совпадают с отчётом
python payment_cost.py --check 1700  # цена одного чека тремя способами
python build_data.py                 # пересобрать CSV и JSON для сайта
python figures.py                    # пересобрать графики
```

Открыть калькулятор локально:

```bash
python -m http.server 8000 --directory docs
```

и открыть в браузере `localhost:8000`. Сайт публикуется через GitHub Pages (Settings → Pages → Branch `main`, папка `/docs`) по адресу https://antonshkelll.github.io/sbp-economics/.

## Методология

Цена платежа = min(чек × ставка; потолок) × (1 + НДС, если он не вычитается)

| Блок | Метод |
|---|---|
| Данные | Отчёты Банка России «Развитие НПС», итоги СБП 2023–2025, решения о тарифах 2026 г. |
| Модель | Юнит-экономика чека 300 / 1 700 / 5 000 ₽, экономия бизнеса |
| Устойчивость | Анализ чувствительности к ставке эквайринга и режиму НДС |
| Сравнение | СБП vs Pix (Бразилия) vs UPI (Индия), цифровые валюты центробанков |
| Стратегия | PEST, SWOT, пять сил Портера, стейкхолдеры, 10 типов инноваций Кили, сценарии 2028 |

### Статусы данных

Каждая цифра в `analysis/dataset.py` и `data/sources.csv` имеет один из статусов:

- `primary`: Банк России, тексты решений;
- `secondary`: СМИ и сервисы со ссылкой на первоисточник;
- `disputed`: источники расходятся (перечень в приложении А исследования);
- `author`: расчёт или оценка автора.

Главные допущения: комиссия по картам 1,5–2,5%, по СБП 0,4–0,7%. Модель предполагает, что на комиссию СБП и цифрового рубля НДС не начисляется.
Если это не так, вывод сохраняется: эффективная ставка СБП с НДС составит 0,85%.

## Ограничения

Анализ не доказывает причинность. Комиссии банков взяты из вторичных источников, последние квартальные данные ЦБ относятся ко II кв. 2026,
данные по цифровому рублю ранние. Калькулятор даёт оценку и не является финансовой рекомендацией.
